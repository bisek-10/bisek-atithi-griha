# Public Assets Folder

Place your static images here so they can be served by Vite.

## Files to Add:

1. **`logo.png`**:
   - Recommended size: Around `150px` width, `40px` height.
   - Transparent background.
   - If present, it will automatically replace the textual logo in the header.

2. **`property.jpg`**:
   - Recommended size: `1200px` width, `1500px` height (or aspect ratio 4:5).
   - This will be the main hero image displayed on the landing page.
   - If not present, a beautiful modern minimal illustration and upload slot indicator will be shown instead.

## Example File Layout:
```
public/
├── logo.png
├── property.jpg
└── README.md
```
